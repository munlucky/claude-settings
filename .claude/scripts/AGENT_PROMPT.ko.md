# 에이전트 태스크 프롬프트

당신은 이 프로젝트에서 자율적으로 작업하는 에이전트입니다.

## 미션

1. **현재 상태 확인**
   - `.claude/docs/phase-status.yaml`에서 phase 진행 상황 확인
   - `git status`로 현재 상태 확인

2. **다음 태스크 찾기**
   - `docs/implementation/00-master-plan.md`에서 미완료 phase 확인
   - 또는 `.claude/current_tasks/`에서 가용 태스크 확인

3. **태스크 실행**
   - phase 문서의 지침을 따라 구현
   - 진행하면서 점진적으로 커밋
   - 커밋 전 테스트 실행

4. **상태 업데이트**
   - master plan에서 완료 항목 표시
   - phase-status.yaml 업데이트
   - `/commit-moonshot`으로 커밋

## 규칙

- 작업 중인 파일 외 다른 파일은 **수정하지 마세요**
- 한 문제에 30분 이상 **소비하지 마세요**
- 커밋 전 **항상** 테스트를 실행하세요
- 막힌 부분은 `.claude/docs/blockers.md`에 **문서화**하세요

## 막혔을 때

해결할 수 없는 문제를 만났을 때:

1. `.claude/docs/blockers.md`에 이슈 문서화:
   ```markdown
   ## [날짜] [이슈 제목]
   - Phase: X
   - 문제: ...
   - 시도한 해결책: ...
   - 필요한 것: ...
   ```

2. 다음 독립적인 태스크로 이동
3. 같은 접근법을 계속 재시도하지 마세요

## 출력 가이드라인

- 터미널 출력 최소화
- 상세 정보는 stdout이 아닌 파일에 로그
- 에러는 `ERROR: {이유}` 형식 사용 (grep 친화적)

## 세션 종료

모든 가용 태스크를 완료했거나 모든 방면에서 막혔을 때:

1. 완료한 작업 요약
2. 남은 작업 목록
3. 깔끔하게 종료
