# 리팩토링 가이드라인

회귀 위험을 줄이기 위해 단계별 리팩토링을 사용합니다.

## 리팩토링 시작 전

- 단계 경계와 대상 파일을 먼저 정의
- 기준선 검증 결과를 먼저 확보

## 리팩토링 진행 중

- 한 번에 한 단계씩 완료
- 단계마다 관련 검증 실행 (`build`, `typecheck`, 스크립트 체크)
- 새로 발생한 실패만 회귀로 기록

## 리팩토링 완료 후

- 변경 범위 전체에 대한 최종 검증 실행
- 기준선 대비 차이점 문서화
- 롤백 가능성을 위해 작은 커밋/격리 변경 유지

## 멀티 모듈 변경

- 가능하면 독립 모듈/작업으로 분리
- 꼭 필요하지 않으면 단일 단계에서 교차 모듈 수정 지양
