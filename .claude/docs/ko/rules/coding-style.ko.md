# 코딩 스타일 가이드라인

## 목적

항상 로드되는 스타일 규칙은 짧게 유지하고, 코드만으로 추론하기 어려운 제약만 남깁니다.

## 필수

- 광범위한 재작성보다 작고 집중된 수정 우선
- JS/TS 상태/데이터 변경은 불변 업데이트 우선
- 파일 유지보수성 확보 (하드 캡: 파일당 800줄)
- 의도가 코드만으로 드러나지 않을 때만 주석 추가

## 금지

- 커밋 코드에 디버그 로그(`console.log`) 잔존
- 이슈 참조 없는 `TODO`/`FIXME` 잔존
- 언어/프레임워크 기본 규칙을 중복하는 스타일 전용 규칙 추가

## 프레임워크 특화 참고

- React/Next.js 성능 리뷰는 `.claude/skills/vercel-react-best-practices/SKILL.md` 사용
- React/웹 UI 구현 또는 리디자인에서 시각 방향이 중요하면 코드 생성 전에 `.claude/skills/frontend-design/SKILL.md` 사용
