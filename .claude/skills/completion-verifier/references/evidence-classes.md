# Evidence Classes

- `adapter_smoke`: proves a runtime route can execute. It is never product closeout.
- `workflow_contract`: proves harness invariants, registry rules, or state contracts.
- `product_acceptance`: proves AC/SCN/user-facing outcomes and must satisfy scorecard requirements.
- `runtime_capability`: proves tool, MCP, browser, fork, shell, or worktree availability.
- `host_environment`: proves OS, path, encoding, permissions, or filesystem health.
- `closeout_scope`: proves phase or repository closeout scope.
- `fixture_precondition`: proves seeds and preconditions before product checks run.
