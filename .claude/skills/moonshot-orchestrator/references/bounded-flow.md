# Bounded Orchestrator Flow

- Bounded work has a clear target, limited file scope, and no phase package dependency.
- Inspect project contracts, tests, and nearby code before edits.
- Prefer direct implementation in the current session; use agents only for user-requested delegation or independent sidecar work.
- Keep diffs surgical and do not clean unrelated debt.
- Report changed files, verification, and residual risks without phase-runner lifecycle language.
