# 분석 가이드

## 목적
- 심층 분석, 영향 분석, 아키텍처 조사 메모를 저장합니다.

## 권장 파일
- `docs/analysis/README.md` — 인덱스 및 작성 규칙
- `docs/analysis/YYYY-MM-DD-{topic}.md` — 주제별 조사 문서
- `docs/analysis/impact-{feature}.md` — 변경 영향 분석

## 최소 섹션
- 목표
- 범위
- 발견 사항
- 리스크
- 후속 작업

## 사용 규칙
- 채팅 히스토리 밖에서도 보존할 가치가 있는 분석은 이 폴더에 남깁니다.
- 실행에 영향을 주는 분석은 구현 계획이나 워크플로우 문서에서 링크합니다.
