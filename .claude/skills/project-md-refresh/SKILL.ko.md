# PROJECT.md 현행화

## 목표
근거 기반으로 `.claude/PROJECT.md`를 생성하거나 갱신한다.

> 이 스킬은 생성기이며, 게이트 역할은 `project-contract-gate`가 담당한다.

## 워크플로우
1. 기준 파일을 찾는다.
2. 저장소에서 스택, 명령어, 구조, 규칙 근거를 수집한다.
3. `PROJECT.md` 섹션을 실제 프로젝트 내용으로 채운다.
4. 요약과 함께 어떤 최소 계약 영역이 준비되었는지 보고한다.

## 최소 계약 영역
- 개요
- 명령어
- 테스트 규칙
- 구조/패턴
- Git 워크플로우
- 핵심 규칙 / 경계

## 가드레일
- 추측 금지
- 정보 부족 시 TODO 또는 확인 질문
- 간결하고 프로젝트 맞춤형 유지
