# Plan Package Contract

- A runnable package has one master plan and root-level numbered phase docs.
- Each phase declares dependencies, conflicts, owned paths, staged owned paths, adoption targets, read-only paths, shared mutable paths, merge policy, and live mutation policy.
- Acceptance criteria must map to evidence paths and pass signals.
- Prepared execution artifacts must include sprint contract, QA report, scorecard, handoff, worksets, and goal contract.
- Staged redesign phases must name the later adoption phase that may touch live harness targets.
