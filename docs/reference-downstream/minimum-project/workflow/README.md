# Workflow

## Stage Order

`intake -> plan -> ready/isolate -> execute -> review -> verify -> finish/handoff`

## Approval Boundary

- Human approval is allowed before execution begins.
- After execution begins, do not require repeated human checkpoints inside implementation or verification loops unless a real blocker appears.

## Required Artifacts

- `SPRINT_CONTRACT.md`
- `QA_REPORT.md`
- `HANDOFF.md`
