# Context Readiness Schema

Canonical source guideline for context readiness sections and handoff shape.

Context readiness must name the objective, current repository, relevant source files, verification contract, and known blockers.
Separate confirmed facts from assumptions; assumptions must be explicit and traceable to the task or user request.
Handoffs should include commands already run, their result, and the smallest next executable step.
Do not copy raw transcripts into readiness artifacts; summarize decisions and cite local paths when the next agent must inspect them.
