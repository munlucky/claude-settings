# Skill Composition

Canonical source guideline for composing skills without hiding ownership or evidence boundaries.

Use the smallest set of skills that covers the task and state why each skill is active.
A skill may delegate to references or scripts, but ownership of decisions and verification must remain visible.
Do not create a new public skill when an existing owner plus a guideline update is sufficient.
When multiple skills apply, sequence them by workflow stage: context, planning, implementation, review, verification, closeout.
