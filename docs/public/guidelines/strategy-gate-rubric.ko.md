# Strategy Gate Rubric KO

전략 gate readiness review의 canonical source guideline입니다.

전략은 문제, 제약, 사용자 가치, 범위 경계, 검증 경로가 명확할 때 준비된 것으로 봅니다.
숨은 가정, 과도한 rewrite, owner 없는 runtime behavior에 의존하는 전략은 통과시키지 않습니다.
핵심 사용자 flow나 harness contract를 보존하는 가장 작은 가역적 계획을 선호합니다.
gate feedback은 문체 지적이 아니라 구체적인 plan edit 또는 blocker를 만들어야 합니다.
