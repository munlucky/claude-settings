# MemoryGraph Workflow

Canonical source guideline for MemoryGraph refresh, promotion, and generated-state boundaries.

Project MemoryGraph refresh should index the current codebase and write generated graph state outside tracked source.
Use account-root project knowledge state for new writes unless an explicit compatibility override is supplied.
Promotion to reusable harness memory requires explicit approval, redaction, and a short recurrence lesson.
Commit workflows may run memory refresh checks, but memory artifacts remain unstaged unless the user asks to include them.
