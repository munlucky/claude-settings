# Strategy Gate Rubric

Canonical source guideline for strategy readiness review.

A strategy is ready when the problem, constraints, user value, scope boundary, and verification path are explicit.
Reject strategies that depend on unstated assumptions, broad rewrites, or unowned runtime behavior.
Prefer the smallest reversible plan that preserves the main user or harness contract.
Gate feedback should produce concrete plan edits or blockers, not style-only commentary.
