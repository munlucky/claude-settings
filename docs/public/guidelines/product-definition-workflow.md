# Product Definition Workflow

Canonical source guideline for product-definition planning artifacts and readiness review.

Product definition starts from user goal, target audience, main workflow, constraints, and explicit non-goals.
PRD, SPEC, DESIGN, and task slices should trace back to the same acceptance scenarios.
Use an assumption ledger for ambiguity; stop only when an assumption would create material product or safety risk.
Before implementation, review whether the plan is demoable, verifiable, and narrow enough to execute without hidden scope.
