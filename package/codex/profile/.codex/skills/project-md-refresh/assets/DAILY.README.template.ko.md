# Daily 기록 가이드

## 목적
- 여러 에이전트의 일일 기록을 예측 가능한 한 곳에 모읍니다.

## 디렉터리 규칙
모든 일일 기록은 아래 경로를 사용합니다.

```text
docs/daily/YYYY-MM-DD/
```

필수 파일:
- `codex.md`
- `claude.md`
- `kimi.md`

## 반드시 기록할 내용
- 큰 구조 변경
- 파일 이동 또는 삭제
- 검증 결과
- 주요 결정 또는 blocker

## 기록 규칙
- 같은 날짜에는 같은 파일에 누적 기록합니다.
- 프로젝트 팀의 로컬 시간을 기준으로 기록합니다.
- 긴 서술보다 짧고 사실적인 로그를 우선합니다.

## 엔트리 템플릿
```markdown
## [HH:MM] 작업 항목
- 요청:
- 변경 파일:
- 검증:
- 메모:
```
