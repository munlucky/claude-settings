# Independent Review Loop

- Reviewer agents are sidecar evaluators. Parent session owns final plan edits.
- Review loops check product value, architecture integrity, execution readiness, adoption safety, and stale state risk.
- Accepted findings must be reflected in the master plan or phase docs with concrete evidence.
- Rejected findings should be summarized only when they explain an intentional tradeoff.
- Do not let review iterations change live harness source during planning.
