# Daily Log Guide

## Purpose
- Keep cross-agent daily records in one predictable place.

## Directory Rule
All daily records live under:

```text
docs/daily/YYYY-MM-DD/
```

Required files:
- `codex.md`
- `claude.md`
- `kimi.md`

## What Must Be Recorded
- large structural changes
- file moves or deletions
- verification results
- notable decisions or blockers

## Logging Rules
- Append to the same file for the same day.
- Use local time for the project team.
- Prefer short factual entries over narrative logs.

## Entry Template
```markdown
## [HH:MM] Work Item
- Request:
- Changed files:
- Verification:
- Notes:
```
