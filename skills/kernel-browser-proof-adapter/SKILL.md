# kernel-browser-proof-adapter

Use only when browser behavior is part of acceptance, required verification, or necessary to judge completion. Bind evidence to the scenario, target, source identity, mutation revision, depth, interaction outcome, artifact references, timestamp, and verdict. A browser adapter records verification evidence; it cannot complete a run by itself.
