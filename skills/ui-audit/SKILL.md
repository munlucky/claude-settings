# UI Audit

This is a standalone, read-only analysis utility. It may write an audit artifact outside the project source tree, but it never edits source, Git, Kernel proof, protected review receipts, Project Knowledge, or completion state.

`PASS` is informational only. A UI change must be implemented through the Kernel, and a protected review obligation can be satisfied only by a fresh Kernel-recorded independent review receipt.
