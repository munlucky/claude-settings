# kernel-conditional-frontend-guidance

Activate only when the Kernel contract or changed paths indicate frontend or visual behavior work. Preserve the existing design context, reuse tokens and components, cover responsive and accessibility states, and model loading, empty, error, and persistence states. This is conditional guidance, not a separate execution stage or completion authority.
