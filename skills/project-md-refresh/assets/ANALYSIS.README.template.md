# Analysis Guide

## Purpose
- Store deep-dive analysis, impact assessments, and architecture investigation notes.

## Recommended Files
- `docs/analysis/README.md` — index and conventions
- `docs/analysis/YYYY-MM-DD-{topic}.md` — focused investigation
- `docs/analysis/impact-{feature}.md` — change impact analysis

## Minimum Sections
- Goal
- Scope
- Findings
- Risks
- Follow-up actions

## Usage Rule
- Use this folder for analysis worth preserving beyond chat history.
- Link relevant analysis docs from implementation plans or workflow notes when they affect execution.
