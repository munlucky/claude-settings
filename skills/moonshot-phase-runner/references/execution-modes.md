# Execution Modes

The default interactive execution path is in-session coordination with fresh forked attempts for phase work.

## Primary Path

- Parent session resolves phase state and owns final edits.
- Fresh attempts execute bounded work and return evidence.
- Parent session applies accepted changes and runs closeout gates.

## Legacy Boundary

Delegated-terminal adapters are preserved for compatibility investigation only. Do not auto-start them unless the run explicitly declares a legacy maintenance reason.
